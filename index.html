How it works

One board file in, one page out

# convert a board, images named by asset id go in ./assets
node tools/convert.mjs Board.dc.html --out dist --assets ./assets
cp src/dc-lite.js dist/
npx serve dist
class Component extends DCLogic {
  state = { count: 0 };
  renderVals() {
    return {
      count: this.state.count,
      wave: () => this.setState(s => ({ count: s.count + 1 }))
    };
  }
}
Patches, not repaints

Each render patches the live DOM with morphdom and skips any subtree whose markup did not change, so CSS keyframes never restart.

Refs keep their text

Counters written through ref at 60 fps survive a re-render, the same as in React.

Events that stick

One capturing listener per event type on the root, so handlers outlive patches and media events like onPlaying still fire.

Familiar lifecycle

setState with batching, componentDidMount, componentDidUpdate, componentWillUnmount, destroy().

Supported syntax

What a board can use

{{​ a.b }}

Dotted lookups into renderVals() in text and attributes. False and null render empty.

<sc-for list as>

Repeat children per item, with itemIndex available.

<sc-if value>

Render children when the value is truthy.

onClick="{{​ fn }}"

Any onX handler, delegated from the root.

ref="{{​ fn }}"

Callback and object refs, plus a React.createRef shim.

data-props

Declared defaults become this.props, overridable from DCLite.mount().
